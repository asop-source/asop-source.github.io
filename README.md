Online CV (single-file static site) for **Asop**, Management Information System Manager.

## Editing

Everything lives in `index.html` — HTML content, CSS, and print rules. Edit and push; GitHub Pages redeploys automatically.

The default branch is `master`, and that is the branch GitHub Pages serves — push there, not to `main`.
